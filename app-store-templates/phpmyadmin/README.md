phpMyAdmin is a free software tool written in PHP, intended to handle the administration of MySQL and MariaDB over the web. It provides a convenient visual interface for managing databases, tables, columns, relations, indexes, users, permissions, and more.

## Features

- 🎨 Intuitive web interface
- 📊 Database management
- 📝 SQL query builder
- 👥 User management
- 🔐 Permissions management
- 📈 Import/Export data
- 🔍 Search functionality
- 🎯 Multiple server support
- 📋 Table operations
- 🌐 Multi-language support
- 🔧 Database designer
- 📊 Query statistics

## Default Configuration

- **Port**: 8082
- **MySQL Host**: mysql (container name)
- **MySQL Port**: 3306

## Access

Web UI: `http://localhost:8082`

## Login

Use your MySQL/MariaDB credentials:
- **Server**: mysql (or leave empty if default)
- **Username**: root or your database user
- **Password**: Your database password
