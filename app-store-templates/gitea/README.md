Gitea is a painless self-hosted Git service. It's a community-managed lightweight code hosting solution written in Go.

## Features

- 📦 Easy to install and update
- 💾 Low resource requirements
- 🔐 Built-in user management
- 📝 Issue tracking and project management
- 🔀 Pull requests and code review
- 📊 Repository statistics and graphs
- 🔔 Notifications via email and web
- 🌍 Multiple language support
- 🔌 Webhook integration
- 📱 Mobile-friendly interface

## Migration

Gitea supports migration from:
- GitHub
- GitLab
- Bitbucket
- Gogs
