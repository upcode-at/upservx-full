# Ombi

Ombi is a self-hosted web application that automatically gives your shared Plex, Emby or Jellyfin users the ability to request content by themselves! Ombi can be linked to multiple TV Show and Movie DVR tools to create a seamless end-to-end experience for your users.

## Features

- Request Movies and TV Shows
- Integrates with Plex, Emby, and Jellyfin
- Notification system (Email, Discord, Slack, etc.)
- User management system
- Mobile-friendly responsive design
- Automatic availability checking
