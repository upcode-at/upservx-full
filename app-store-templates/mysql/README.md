MySQL is the world's most popular open-source relational database management system. It's trusted by leading web properties including Facebook, Twitter, YouTube, and many others for its reliability, performance, and ease of use.

## Features

- 🚀 High performance and scalability
- 🔒 Enterprise-grade security
- 💾 ACID compliance
- 🔄 Replication support
- 📊 Full-text search
- 🌐 Multi-platform support
- 🔧 Extensive tools ecosystem
- 📈 Partitioning support
- 🔐 SSL/TLS encryption
- 🎯 JSON support
- 📝 Stored procedures & triggers
- 🔍 Advanced query optimization

## Default Credentials

- **Root Password**: rootpassword
- **Database**: mydb
- **User**: myuser
- **Password**: mypassword
- **Port**: 3306

## Connection Example

```bash
mysql -h localhost -P 3306 -u myuser -p
```
