Vaultwarden is an unofficial Bitwarden-compatible server written in Rust. It's a lightweight, self-hosted password manager that's fully compatible with Bitwarden clients (web vault, browser extensions, mobile apps, and desktop apps).

## Features

- 🔐 Secure password storage with AES-256 encryption
- 🌐 Web vault interface
- 📱 Mobile apps (iOS, Android)
- 🖥️ Desktop apps (Windows, macOS, Linux)
- 🔌 Browser extensions (Chrome, Firefox, Safari, Edge)
- 👥 Organization support for team password sharing
- 📎 Secure file attachments
- 🔑 Two-factor authentication (2FA)
- 💾 Password history
- 🎯 Password generator
- 🔄 Cross-device synchronization
- 📋 Auto-fill credentials
- 💼 Secure notes and identities
- 💳 Credit card storage
- ⚡ Lightweight and fast
- 🆓 Free (no premium required)
