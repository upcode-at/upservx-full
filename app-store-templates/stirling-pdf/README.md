# Stirling PDF

Powerful locally hosted web-based PDF manipulation tool — no data leaves your server.

## Features

- 📄 Merge and split PDFs
- 🗜️ Compress PDFs
- 🔄 Convert to/from PDF (Word, Excel, images, HTML)
- 🔒 Add/remove passwords and permissions
- ✍️ Sign and watermark PDFs
- 🔍 OCR text recognition
- 🖼️ Extract images from PDFs
- 📝 Edit metadata
- 🎨 Beautiful web interface with dark mode
