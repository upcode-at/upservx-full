# Jellyfin Media Server

The Free Software Media System - Your media, your way.

## Features

- 🎬 Movies and TV shows
- 🎵 Music streaming
- 📚 Books and comics
- 📷 Photo libraries
- 📺 Live TV and DVR
- 🎨 Beautiful web interface
- 📱 Mobile apps (iOS, Android)
- 🆓 Completely free and open source
