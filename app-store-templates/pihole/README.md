Pi-hole is a DNS sinkhole that protects your devices from unwanted content without installing any client-side software. It blocks ads at the network level, improving privacy and network performance across all devices on your network.

## Features

- 🛡️ Network-wide ad blocking
- 🚀 DNS-level blocking
- 📊 Detailed statistics dashboard
- 🔒 Privacy protection
- ⚡ Improved performance
- 🌐 Custom blocklists
- 👥 Client management
- 🎯 Whitelist/Blacklist control
- 📱 Mobile friendly interface
- 🔍 Query log analysis
- ⏱️ Real-time monitoring
- 🎨 Group management

## Default Configuration

- **Web Interface Port**: 8084
- **DNS Port**: 53 (TCP/UDP)
- **Web Password**: admin
- **Timezone**: Europe/Vienna

## Access

Web UI: `http://localhost:8084/admin`
