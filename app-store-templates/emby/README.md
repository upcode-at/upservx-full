Emby is a media server designed to organize, play, and stream audio and video to a variety of devices. It's a great alternative to Plex with similar features and excellent device support.

## Features

- 🎬 Movies and TV shows with rich metadata
- 🎵 Music library with artist info
- 📷 Photo albums and slideshows
- 📺 Live TV and DVR (with tuner)
- 📱 Mobile apps (iOS, Android)
- 🖥️ Desktop apps (Windows, Mac, Linux)
- 🎮 Gaming console apps
- 📡 DLNA support
- 🔄 Automatic media organization
- 🎨 Beautiful web interface
