# Jupyter Notebook

Web-based interactive computing platform that allows you to create and share documents containing live code, equations, visualizations, and narrative text.

## Features

- 🐍 Python, R, and Julia support
- 📊 Data visualization with matplotlib, plotly, and more
- 🧮 Scientific computing with NumPy, SciPy, pandas
- 🤖 Machine Learning with scikit-learn, TensorFlow, PyTorch
- 📝 Rich text support with Markdown
- 🔄 Easy sharing and collaboration
- 📚 JupyterLab interface included

## Getting Started

1. Access Jupyter at `http://your-server-ip:8888`
2. Use the token: `changeme` (change this in the environment variables)
3. Start creating notebooks in the `work` directory

## Default Configuration

- **Port**: 8888
- **Token**: changeme (please change this!)
- **Data Directory**: /opt/upservx/data/jupyter
- **Image**: jupyter/datascience-notebook (includes Python, R, Julia)
