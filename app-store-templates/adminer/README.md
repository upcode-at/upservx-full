Adminer (formerly phpMinAdmin) is a full-featured database management tool written in PHP. It's a lightweight alternative to phpMyAdmin with support for multiple database systems in a single tool.

## Features

- 🎯 Single file deployment
- 🗄️ Multi-database support
- 🚀 Lightweight and fast
- 🎨 Clean interface
- 📝 SQL editor with syntax highlighting
- 📊 Export/Import data
- 🔍 Advanced search
- 👥 User management
- 🔐 Secure by default
- 🌐 Multiple themes
- 📈 Foreign key support
- 🔧 Schema editor

## Supported Databases

- MySQL
- PostgreSQL
- SQLite
- MS SQL
- Oracle
- MongoDB
- Elasticsearch
- And more...

## Default Configuration

- **Port**: 8083
- **Default Server**: mysql
- **Theme**: pepa-linha

## Access

Web UI: `http://localhost:8083`

## Login

Enter your database credentials:
- **System**: Select database type (MySQL, PostgreSQL, etc.)
- **Server**: Database hostname (e.g., mysql, postgres, localhost)
- **Username**: Your database username
- **Password**: Your database password
- **Database**: Database name (optional)
