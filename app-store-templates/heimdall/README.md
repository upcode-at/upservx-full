# Heimdall

**Application Dashboard**

Heimdall is an elegant solution to organise all your web applications. It provides a clean, beautiful dashboard where you can add links to any web application or website with custom icons and colours.

## Access

| Protocol | URL |
|---|---|
| HTTP | `http://<host>:8888` |
| HTTPS | `https://<host>:8889` |

## Configuration

| Variable | Default | Description |
|---|---|---|
| `PUID` | `1000` | User ID for file permissions |
| `PGID` | `1000` | Group ID for file permissions |
| `TZ` | `Europe/Berlin` | Timezone |

## Data

Configuration and app data are stored in `/opt/upservx/data/heimdall`.
