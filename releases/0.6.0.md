## Release v0.6.0 - Cluster HA & UX Improvements

**Release Date:** 2026-06-06

### What's New in UpservX v0.6.0

This release improves cluster failover behavior, makes cluster state more consistent across master and child nodes, and brings the Cluster module UI in line with the other modules.

---

### Highlights

#### High Availability Cluster Coordination

- **VIP owner propagation**: New endpoint `POST /cluster/ha/vip-owner-update` distributes the current VIP owner state across the cluster.
- **Expanded HA diagnostics**: Cluster status now includes `vip_owner_hostname`, `vip_owner_ip` and the active HA interface.
- **Direct interface VIP binding**: VIPs are now placed directly on the configured physical interface instead of a dedicated dummy interface.
- **Local-only HA settings**: Node-local HA settings are no longer synchronized to other nodes, reducing unintended state overwrites.

#### Cluster Topology & Sync Behavior

- **Full cluster view for child nodes**: Child nodes now load the same complete cluster view from the master that the master itself exposes.
- **Reliable node removal**: Cluster node removal now resolves nodes by multiple identifiers, including stored hostname, original hostname, assigned hostname and IP address.
- **Best-effort force leave**: Removing offline child nodes no longer fails due to unreachable cleanup notification delivery.
- **Stable deleted-node state**: `GET /cluster/info` no longer rewrites node config files during polling, so removed nodes stay removed.

#### UI & Operational Safety

- **Locked HA settings while active**: HA configuration inputs are disabled while HA is enabled to prevent unsafe live edits.
- **English-standardized cluster labels**: Remaining HA and cluster-adjacent UI texts are now consistent with the rest of the interface.
- **Full-width Cluster tabs**: The Cluster module tab bar now stretches across the full page width like the other modules.

---

### Upgrade Notes

- No database migration required for this release.
- If you previously deployed HA with VIPs on dummy interfaces, verify your configured physical interface after upgrading.
- Existing HA configurations should continue to work, but local-only HA settings should now be managed per node.
