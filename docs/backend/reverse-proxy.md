# Reverse Proxy Management

**File:** `upcode-harbor-service/reverse_proxy.py`
**API sub-module:** `upcode-harbor-service/api/reverse_proxy.py`

**Required permission:** Admin (`sudo`/`wheel`)

---

## Overview

Upcode Harbor manages **reverse proxy configurations** for Nginx and/or Caddy. This enables pointing external domains or ports to internal services.

---

## Proxy Backend Detection

```python
if shutil.which("nginx"):
    PROXY_BACKEND = "nginx"
elif shutil.which("caddy"):
    PROXY_BACKEND = "caddy"
else:
    PROXY_BACKEND = None
```

---

## Data Model: `ProxyRoute`

```python
class ProxyRoute(BaseModel):
    id: str
    name: str
    listen: str         # e.g. "443", "0.0.0.0:8080"
    domain: str         # e.g. "app.example.com"
    target: str         # e.g. "http://localhost:3000"
    ssl: bool
    ssl_cert: str       # Path to certificate
    ssl_key: str        # Path to key
    auth: bool          # Require basic auth
    auth_user: str
    ws_support: bool    # WebSocket proxy headers
    headers: Dict[str, str]  # Custom response headers
    enabled: bool
```

---

## Nginx Integration

Configs are written to `/etc/nginx/sites-available/upcode-harbor-<name>.conf` and symlinked into `sites-enabled/`.

Template:
```nginx
server {
    listen {port} {ssl};
    server_name {domain};

    {ssl_block}

    location / {
        proxy_pass {target};
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        {ws_headers}
        {custom_headers}
    }
}
```

After changes: `nginx -t && systemctl reload nginx`

---

## Caddy Integration

Routes are written to a JSON file at `/etc/caddy/upcode-harbor.json` and loaded via `caddy reload`.

Template:
```json
{
  "handle": [
    {
      "handler": "reverse_proxy",
      "upstreams": [{"dial": "{target_host}:{target_port}"}]
    }
  ],
  "match": [{"host": ["{domain}"]}]
}
```

## SSL Certificate Management

| Feature | Description |
|---|---|
| Let's Encrypt | Via Caddy (automatic) or certbot (manual) |
| Self-signed | Generated by Upcode Harbor via `openssl req -x509 ...` |
| Custom cert | Upload via API endpoint |

## API Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/proxy/routes` | All proxy routes |
| `POST` | `/proxy/routes` | Create new route |
| `GET` | `/proxy/routes/{id}` | Route details |
| `PUT` | `/proxy/routes/{id}` | Edit route |
| `DELETE` | `/proxy/routes/{id}` | Delete route |
| `POST` | `/proxy/routes/{id}/enable` | Enable route |
| `POST` | `/proxy/routes/{id}/disable` | Disable route |
| `GET` | `/proxy/status` | Backend status |
| `POST` | `/proxy/reload` | Reload proxy |
| `GET` | `/proxy/ssl/certs` | Available certificates |
| `POST` | `/proxy/ssl/generate` | Generate self-signed cert |
| `POST` | `/proxy/ssl/upload` | Upload certificate |
